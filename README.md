# এসপি ওয়েদার — বাংলাদেশের আবহাওয়া, সংবাদ ও সতর্কবার্তা

React + Vite + Tailwind CSS 4 দিয়ে তৈরি সম্পূর্ণ বাংলা আবহাওয়া প্ল্যাটফর্ম।

## বৈশিষ্ট্য

- ৬৪ জেলার বর্তমান আবহাওয়া (Open-Meteo API, লাইভ)
- ঘণ্টাভিত্তিক পূর্বাভাস + Recharts চার্ট (তাপমাত্রা ও বৃষ্টির সম্ভাবনা)
- ৭ দিনের ও ১৬ দিনের পূর্বাভাস (১৬ দিনের জন্য অনিশ্চয়তার সতর্কবার্তাসহ)
- জেলা ডিরেক্টরি: বিভাগ ফিল্টার, খোঁজ, জেলার বিস্তারিত পাতা
- Leaflet মানচিত্র: প্রধান ১২ জেলার তাপমাত্রা চিহ্ন
- আবহাওয়া সংবাদ: ১০টি সম্পাদকীয় ব্যাখ্যামূলক নিবন্ধ, বিভাগ ফিল্টার, খোঁজ, শেয়ার
- সতর্কবার্তা: সৎ উপস্থাপনা — যাচাইকৃত সরকারি সতর্কবার্তা না থাকলে স্পষ্টভাবে জানানো হয়; BMD ও FFWC লিংকসহ
- গ্লোবাল খোঁজ (জেলা, সংবাদ, পাতা), কীবোর্ড নেভিগেশন
- হালকা/অন্ধকার মোড, °C/°F, জেলা মনে রাখা, হালনাগাদের বিরতি — LocalStorage-এ সংরক্ষিত
- PWA: ম্যানিফেস্ট, সার্ভিস ওয়ার্কার, অফলাইন পাতা, ক্যাশ করা তথ্য "সংরক্ষিত তথ্য" হিসেবে চিহ্নিত
- সম্পূর্ণ বাংলা ইন্টারফেস, বাংলা সংখ্যা, Asia/Dhaka সময়

## তথ্যসূত্র ও সততা

- আবহাওয়া: [Open-Meteo](https://open-meteo.com) — বিনামূল্যে অ-বাণিজ্যিক ব্যবহারের শর্ত প্রযোজ্য।
- সরকারি সতর্কবার্তা: [বাংলাদেশ আবহাওয়া অধিদপ্তর](https://bmd.gov.bd/) ও [বন্যা পূর্বাভাস ও সতর্কীকরণ কেন্দ্র](https://ffwc.gov.bd/)।
- ভুয়া লাইভ আবহাওয়া, বানানো সতর্কবার্তা বা বানানো সংবাদ নেই। সংবাদগুলো সম্পাদকীয় ব্যাখ্যামূলক নিবন্ধ।
- ১৬ দিনের পূর্বাভাস নিশ্চিত নয় — অ্যাপে স্পষ্টভাবে জানানো হয়।
- মানচিত্রের চিহ্নগুলো জেলার অবস্থান দেখায়; এটি লাইভ রাডার চিত্র নয়।

## চালানো

```bash
npm install
npm run dev      # ডেভ সার্ভার
npm run build    # প্রোডাকশন বিল্ড -> dist/
npm run preview  # বিল্ড প্রিভিউ
```

## Vercel-এ ডিপ্লয়

- Framework: Vite, Build command: `npm run build`, Output: `dist`
- `vercel.json`-এ SPA রিউরাইট দেওয়া আছে, তাই ডিপ লিংক রিফ্রেশেও কাজ করবে।
- কোনো সার্ভার, ডেটাবেস বা পেইড API লাগে না।

## অ্যাডমিন প্যানেল সম্পর্কে

এই সংস্করণে অ্যাডমিন প্যানেল ইচ্ছাকৃতভাবে বানানো হয়নি — ভুয়া লগইন বা হার্ডকোড করা পাসওয়ার্ড দিয়ে অ্যাডমিন বানানো নিরাপদ নয়। সংবাদ প্রকাশের জন্য ভবিষ্যতে সঠিক প্রমাণীকরণসহ CMS/ডেটাবেস (যেমন Supabase, Sanity বা অন্য কোনো হেডলেস CMS) যুক্ত করতে হবে; তখন `src/data/news.json` ও `src/data/alerts.json`-এর জায়গায় সেই CMS-এর API বসবে।
